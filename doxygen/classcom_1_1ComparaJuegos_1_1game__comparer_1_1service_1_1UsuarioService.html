Detailed Description

Servicio de autenticación de usuarios para Spring Security.

Implementa UserDetailsService para que Spring Security pueda cargar los datos de un usuario durante el proceso de login. El identificador de autenticación es el email del usuario.

Carga un usuario por su email para autenticación.

Busca el usuario en base de datos por email y construye un objeto UserDetails con sus credenciales y rol. Si el usuario no tiene rol asignado, se le otorga el rol por defecto USER.

Parameters
emailEmail del usuario que intenta autenticarse.
Returns
UserDetails con las credenciales y roles del usuario.
Exceptions
