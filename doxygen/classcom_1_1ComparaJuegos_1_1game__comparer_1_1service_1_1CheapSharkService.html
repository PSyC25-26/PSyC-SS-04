Detailed Description

Servicio para obtener precios de juegos desde la API de CheapShark.

Consulta la API pública de CheapShark (cheapshark.com/api/1.0) para buscar deals de Steam (storeID=1) y Epic Games Store (storeID=25). Para juegos no disponibles en CheapShark (p.ej. juegos free-to-play), BusquedaService aplica fallbacks adicionales.

Busca los precios actuales de un juego en Steam y Epic Games Store.

Realiza dos llamadas a la API de CheapShark:

  1. Búsqueda por título para obtener el gameID.
  2. Detalle del juego para obtener sus deals por tienda.

También extrae el steamAppID del resultado de búsqueda para que BusquedaService pueda usarlo como fallback hacia la API de Steam.

Parameters
gameNameNombre del juego a buscar (proveniente de IGDB).
Returns
DTO con los precios y URLs de Steam y Epic. Los campos son null si no se encontró precio para esa tienda.
